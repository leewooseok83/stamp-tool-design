## 대표께 먼저 드리는 3줄

1. **무엇** — 홈페이지·슬라이드 메이커·무료 도구 8종·홍보·유입경로를 공개된 것만으로 끝까지 실측했습니다(사이트 전수 크롤, 슬라이드 메이커 실제 변환 1회, 네이버 검색어 36개, 정책·법령 원문 90여 건). 그 위에 「무엇이 잘못됐고 무엇이 빠졌는지」와 「30일·90일·1년에 무엇을 할지」를 적었습니다.
2. **결론** — 지금 디시전메이커는 **「만들어는 놓았지만 손님이 못 찾고, 찾아와도 돈을 낼 수 없고, 와도 재지 못하는」 상태**입니다. ①결제가 시험 모드(카드사 심사 중)라 매출이 0원일 수밖에 없고 ②검색엔진에 잡힌 페이지가 네이버 2쪽·다음 0쪽이라 검색 손님이 거의 없으며 ③방문을 재는 외부 도구가 없습니다. 제품은 HWPX 변환 1건 실측에서 글자 99.7%·표 3·그림 2가 개수대로 보존되고 10초에 끝났습니다(1회 측정·우리가 만든 자로 잰 값). 다만 「경쟁보다 낫다」고 말할 증거는 아직 없고, PDF→HWP(한글)를 내건 경쟁(HiPDF)이 있어 HWPX가 「경쟁 없는 간판」은 아닙니다.
3. **대표가 하실 일** — 이번 주 세 가지: ①토스페이먼츠에서 심사가 어디서 막혔는지 확인(대표만 가능) ②처리방침·설명글 정합 초안을 승인해 먼저 배포 ③그다음 네이버·구글에 사이트 등록·색인 요청(돈 0원·클릭). 순서와 카드는 실행계획 파일에 있습니다.

## 0. 읽는 법과 낱말 풀이

| 낱말 | 한 줄 풀이 |
|---|---|
| 색인 | 검색엔진이 「이 페이지가 있다」고 등록해 둔 것. 색인이 없으면 검색에 안 나온다 |
| 유입경로(유입 출처) | 손님이 어디서 왔나 — 검색·링크·직접 입력·SNS |
| 메타 설명 | 검색 결과 제목 아래 두 줄 요약. HTML 머리에 적는다 |
| OG 이미지 · og:url | 카카오톡·페이스북에 링크를 붙일 때 뜨는 미리보기 그림과 그 페이지의 공식 주소 |
| 대표 주소(canonical) | 같은 페이지로 가는 주소가 여럿일 때 「이것이 대표」라고 검색엔진에 알리는 표시 |
| 구조화 데이터(ld+json) · sameAs | 「이 페이지는 회사/도구이고 공식 SNS는 여기」를 기계가 읽게 적은 꼬리표 |
| 사이트맵 | 「우리 페이지 목록」을 검색엔진에 알려 주는 파일 |
| 서치어드바이저 / 서치콘솔 | 네이버·구글이 사이트 주인에게 주는 무료 관리 창. 색인 요청과 노출·클릭 수 |
| 시험 결제(테스트 키) / 라이브 키 | 돈이 안 나가는 가짜 승인 / 심사 통과 뒤 받는 진짜 결제 열쇠 |
| 롱테일 검색어 | 「원고지 매수 계산」처럼 작고 구체적인 검색어. 경쟁이 적다 |
| 얇은 콘텐츠 | 단추만 있고 설명 글이 거의 없는 페이지. 검색·광고 심사에 불리 |
| 브라우저 저장소(localStorage) | 손님 브라우저 안에 값을 남기는 칸. 쿠키와 달리 서버로 자동 전송되지 않는다 |
| 무료 몫(quota) | 하루에 무료로 쓸 수 있는 횟수를 세는 장치 |
| 접근 로그 | 웹서버가 요청마다 자동으로 남기는 기록(보통 IP·시각·주소 포함) |
| 정지점 | 대표 승인이 필요해 자동 진행을 멈추는 자리 |

## A2. 슬라이드 메이커 실측

입력: 우리가 만든 가상 문서 PDF(A4 6쪽, 표 3·그림 2·목록 2, 1,576자). 대표 허락 아래 하루 1회 무료 체험으로 변환. 결제 창은 뜨지 않았고 누르지도 않았다. 상세·5칸 표는 조사 파일에 있다(표 끝).

| 항목 | 우리 PDF→HWPX | 우리 PDF→PPTX | iLovePDF PDF→PPTX(무료) | Smallpdf(확인 실패) |
|---|---|---|---|---|
| 결과 쪽 수 | 6쪽 | 6장(화면 기록) | 6장 | — |
| 글자 보존(공백 제거 1,185자) | 99.7% | 미측정 | 99.7% | — |
| 표 / 그림 **개수** | 3 / 2 | 3 / 2(화면 기록) | 3 / 2 | — |
| 올리기→받기 | 10.1초 | 변환 2.7초, 받기 실패 | 14.0초 | 140초+ 무반응 |
| 클릭 수 | 4번(한 화면) | 4번 | 미측정 | — |
| 꼬리표 | 쪽 수는 추정(XML 기준, 한글 프로그램 없음) · 나머지 확인됨 | 변환 성공은 확인됨, 파일은 조사 오류로 유실 | 확인됨 | 확인 실패(자동화 차단 추정) |

이 표에서 말할 수 있는 것과 없는 것:
- **말할 수 있는 것** — HWPX 변환 1건이 글자·표·그림 개수를 보존하고 10초 안에 끝났다. 가입 없이 한 화면에서 4번 눌러 끝난다(우리 자체 특성).
- **말할 수 없는 것** — 「경쟁보다 빠르다·낫다」. 비교 상대 iLovePDF는 **PPTX** 변환이라 다른 기능이고, 측정은 각 1회이며, 보존율의 자(글자 집합·순서 비교)와 판정자가 모두 우리다. 같은 기능(PDF→HWP)을 파는 HiPDF는 재지 않았다 → 실행계획 T-12. PPTX 품질 수치는 파일 유실로 없다 → T-11(3회 측정).
- **경쟁 지형** — 비교한 6곳 중 HWPX 확장자를 내건 곳은 없다. 그러나 HiPDF는 PDF→HWP(한글)를 전면 상품으로 걸었고(확인됨, 경쟁 원문), 한글 프로그램을 가진 한컴이 같은 기능을 내걸면 「HWPX 간판」은 하루에 사라질 수 있다(추정). 「PDF HWPX」는 네이버 자동완성에 없어 **수요가 작을 가능성**이 있다(확인됨 · 키워드 조사).
- 5칸 표(측정일·같은 입력·방법·양쪽 원본·판정자)는 조사 파일 ④절에 있으나 「양쪽 원본」에 우리 PPTX가 없고 판정자가 우리 자신이라, **대외 문구의 실증 자료로는 아직 부족**하다.

# B부. 비판 — 무엇이 잘못됐고 무엇이 빠졌나

## B1. 「매출 0 구조」의 원인 사슬

```
 손님이 못 찾는다            찾아와도 못 낸다           와도 모른다
 (색인 2쪽 · 링크 0)   →   (결제 시험 모드)    ←→   (측정 0)
```

| 고리 | 끊긴 정도 | 푸는 데 드는 것 | 누가 | 걸리는 시간 | 꼬리표 |
|---|---|---|---|---|---|
| 결제 | 완전히(돈 0원) | 토스 심사 완료·반려 사유 확인·라이브 키 전환 | 대표만 | 카드사 심사 통상 7영업일, 최대 14일 | 확인됨(토스 원문) |
| 측정 | 외부 0 | 서치어드바이저·서치콘솔(돈 0) + 청지기 열어 보기 | 대표(클릭)+로컬 | 등록 반나절, 숫자가 쌓이기까지 수 주 | 추정 |
| 노출 | 거의 끊김 | 정합 → 404·사이트맵 → 색인 요청 → 안내 글 → 허용 채널 | 로컬 Claude + 대표 | 수집 반영 「최소 1일~수 주」(네이버·구글 원문), 효과는 수 개월 | 확인됨(원문)/추정 |

**판단:** 셋을 동시에 시작하되 **순서가 있다** — ①사실과 다른 문구(처리방침·메타 설명)를 먼저 고쳐 배포하고 ②그다음 색인 요청을 한다(거짓 상태를 먼저 퍼뜨리지 않기 위해). 결제는 대표가 병행한다. 그리고 결제가 열려도 **수요가 있는지는 모른다**([빈칸 #5]) — 1쪽 50원 단가는 월 100건이 팔려도 3만 원(추정)이라, 변환은 「수익 모델」이라기보다 「무료 체험의 유료 꼬리」이고, 돈은 손님 수가 쌓인 뒤의 일이다.

## B2. 메시지 불일치 — 누구에게 말하는 홈페이지인가

| 손님 | 홈에서 보는 것 | 어디에 |
|---|---|---|
| 서류를 다루는 직장인·자영업자(돈을 낼 사람) | 제목 「PDF→PPTX 변환」, 유료 구역, 요금표 | 제목 1줄 + 아래쪽 |
| 생활 도구를 찾는 일반인(검색 손님 후보) | 무료 도구 8장 | 가운데 |
| 기관·국방 의사결정자(ADMS·M&S) | 첫 화면 슬로건, 여덟 가지 가치, 기술 구역, 장식용 시뮬레이션, ATP DEMO | 첫 화면 전체 |

- 첫 화면은 세 번째 손님용이다. 그런데 **검색 손님은 홈이 아니라 도구 페이지·슬라이드 홈으로 바로 떨어진다**(추정 — 진입 페이지 분포는 [빈칸 #1]). 홈으로 오는 손님은 브랜드 검색·지인·기관일 가능성이 높다. 그래서 첫 화면 재배치(T-09)는 **진입 분포를 본 뒤** 결정하고, 그 전에는 「현행 유지 + 진입 단추 2개 + 시연 표기」가 안전하다.
- 「검색하다 들르고, 즐겨찾기에 남는 도구」 — 들를 수가 없다(색인 없음). 목표와 수단이 끊겨 있다.
- 「LIVE SIMULATION RUNS 128」은 코드 주석상 **장식용** 숫자다. 「Data-driven」을 말하는 회사의 첫 화면에 둘 것이 아니다(헌장 정직 원칙). 「시연용 애니메이션」 표기가 최소 조치다. **로고·슬로건은 뿌리이므로 어떤 안에서도 보존한다.**
- 홈 요금 비교표는 **미출시 기능**의 요금을 남의 구독 요금과 견주는 대외 비교 문구다. 5칸 표가 없으면([빈칸 #15]) 규칙상 내리거나 「준비 중 기능의 예정 요금」임을 분명히 해야 한다 → L-06.

## B5. 무료 도구의 유입·수익 기여

- 무료 도구 7종은 **광고가 거의 없는 검색어**에 자리한다(28개 중 3개). 색인만 되면 들어갈 수 있는 땅인데 간판(색인·그림·제목)을 안 달았다.
- 도구 페이지는 단추만 있고 설명이 짧아 **얇은 콘텐츠**로 분류될 위험이 있다(확인됨 · 애드센스 불승인 사유 원문). AI 브리핑이 28개 중 23개에 뜨므로, 안내 글은 「질문-답」 꼴로 쓴다.
- 도구→도구→유료 변환의 **상호 링크가 없다**. 검색 손님은 도구 페이지로 떨어지므로 그 안에 다음 길이 있어야 한다.
- 수익: 무료 도구에 애드센스를 달면 「쿠키 안 씀·IP 없음」 약속과 충돌(확인됨 · 구글 원문: 비개인화 광고도 쿠키 사용). 이 약속이 jakup과의 차별점이므로 **7종에는 광고를 넣지 않는다.** 단, 솔로몬에 애드센스를 두고 「약속이 차별점」이라 말하면 손님 눈에 일관성이 약하다 — 솔로몬 유지 조건은 C1 ②.

## 부록 2. ADMS화 여부

벤치마킹 대상은 경쟁 서비스·도구 모음 사이트의 **원리**(수익 구조·흐름·조건)이며 문장·화면은 가져오지 않았다.

| 기준 | 상태 |
|---|---|
| ① 표현 미복사 | 이 보고서·요약·실행계획·빈칸·축적층 × PDF 경쟁 원문 6곳 = 0건(`컨설팅/점검/15자_대조_결과.md`). 15자 미만 어순 변형 1건(가리기 문구)은 검토에서 잡혀 P-01에 「다시 쓴다」로 반영 |
| ② 버린 것·이유·잃은 것 | 무료 도구 광고(쿠키 충돌·손님 없음 / 광고 수입) · 유료 검색 광고(예산 0·격전지 / 빠른 노출 — 측정용 소액 시험은 대표 결정으로 남김) · 커뮤니티 홍보 글(규정 / 단기 방문) · 구글 애널리틱스(약속 / 정밀 분석 — 쿠키 없는 분석기는 선택지로 남김) |
