방법: curl로 HTML·스크립트를 내려받아 글과 동작 코드를 읽었다. **브라우저로 화면을 띄우지 않았다**(화면 배치·색은 관찰하지 않음 — 규칙 §3-3-1 ②와도 맞는다). 화면 캡처는 저장하지 않았다.

## 3. 기능 관찰(원리만)

| 칸 | 싸인오케이 | 스탬프NG | 도뉴 |
|---|---|---|---|
| 회사 성격 | 인증기관 계열 전자계약 서비스의 체험 기능 | 도장 이미지 전문 무료 사이트 | 전자계약 서비스의 유입용 기능 |
| 입력 글자 수 | 최대 9자 | 원형·타원 1~4자, 사각 계열 1~16자, 결재인 1~2자 | 최대 14자 |
| 모양 | 5가지 용도 선택(개인·법인·인감·낙관·간인 이름) | 5모양 × 기본/수제 × 양각/음각 | 서버가 개인용·법인용 목록을 한꺼번에 돌려줌 |
| 글씨체 | 서버가 여러 글씨체 결과를 목록으로 돌려줌(수 미확인) | 17종(명조 4·고딕 6·붓 7) | 미확인 |
| 색·굵기 | 미확인 | 테두리 굵기·잉크 느낌·색 조절 | 미확인 |
| 출력 | 내려받기 | 512×512 투명 PNG, 복사, 공유, 투명/흰 배경 비교 | 이미지 선택 → 전자메일 보내기 기능 있음 |
| 단계 수 | 입력 → 만들기 → 고르기 → 내려받기(+동의 창) | 4단계 마법사 → 완성 화면 → 저장 | 입력 → 만들기 → 고르기 |
| 이름이 서버로 가나 | **간다**(POST, 동의서에 이름·전자메일 3년 보유) | **간다**(FAQ: 일시 전송, 원문은 로그에 안 남김) | **간다**(POST) |
| 광고·회원가입 | 광고 코드 없음 · 체험은 비회원 | 애드센스 코드 있음 · 비회원 | 카카오 픽셀(추적) 코드 있음 · 비회원 |
| 법적 고지 | 도장 페이지 본문에 효력 고지 안 보임 | 약관·FAQ에 「인감 등록·전자서명 아님」, 사칭·위조 금지 | 메타 설명에 「인감도장」을 홍보 문구로 씀(오히려 오인 소지) |

## 4. 원리로 뽑은 좋은 점 / 아쉬운 점

| 사이트 | 좋은 점(원리) | 아쉬운 점(원리) |
|---|---|---|
| 싸인오케이 | 용도(개인·법인 등)로 먼저 고르게 해 초보가 덜 헤맴 · 결과를 여러 개 한꺼번에 보여 줘 비교가 쉬움 | 도장 하나에 이름·전자메일 동의를 받음(문턱) · 서버 생성 |
| 스탬프NG | 모양별 글자 수 한도를 미리 알려 줌 · 저장 후 문서 넣는 법까지 안내 · 투명/흰 배경 비교 | 이름이 서버로 감 · 여러 단계 마법사(한 화면 아님) · 광고 코드 |
| 도뉴 | 한글/한자 입력 검사를 입력 단계에서 함 · 개인·법인 결과를 한 번에 | 이름이 서버로 감 · 「인감도장」 홍보 문구 |

**우리에게 남는 빈자리(차별 후보)**: ①이름이 **서버로 한 번도 가지 않는** 도장 도구는 세 곳 중 **없다** ②한 화면에서 입력과 결과가 함께 보이는 구성 ③동의·회원·광고 없음.

## 5. 창을 닫았다

관찰은 위 메모로 끝냈다. 설계서 화면 구성은 이 메모의 「원리」 칸과 우리 요구(README §2-9)에서만 뽑는다. 원문 파일(`점검/원문_*.txt`)은 15자 대조용으로만 쓴다.
