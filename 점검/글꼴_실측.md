## 2. OFL 1.1 조건 중 이 도구에 걸리는 것 (OFL.txt 원문 인용)

【인용】 출처: https://github.com/google/fonts/blob/main/ofl/notoserifkr/OFL.txt · 확인 2026-10-02

- «1) Neither the Font Software nor any of its individual components, in Original or Modified Versions, may be sold by itself.» → 글꼴 파일만 따로 팔지 않는다.
- «2) Original or Modified Versions of the Font Software may be bundled, redistributed and/or sold with any software, provided that each copy contains the above copyright notice and this license.» → `fonts/LICENSES/`에 원문을 함께 둔다.
- «3) No Modified Version of the Font Software may use the Reserved Font Name(s) unless explicit written permission is granted by the corresponding Copyright Holder.» → 줄인 판은 이름을 바꾼다.
- «The requirement for fonts to remain under this license does not apply to any document created using the Font Software.» → 사용자가 만든 도장 PNG에는 OFL 조건이 따라가지 않는다.

## 4. 쓰지 않은 방법과 이유

- Google Fonts 서버에서 바로 불러오기: 글자 구역별 파일을 「입력한 글자에 따라」 받게 되어 서버 기록에 흔적이 남고, 제3자 요청이 생긴다 → 우리 서버에 줄인 파일을 올린다.
- 주소 끝에 필요한 글자만 적어 받는 방식(`&text=`): **입력한 이름이 그대로 주소에 실린다** — 절대 쓰지 않는다.
