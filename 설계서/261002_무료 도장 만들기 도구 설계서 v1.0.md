# 디시전메이커 무료 도장 만들기 — 설계서 v1.0

> 작성: 2026-10-02 · 클라우드 세션(Claude Code on the web) · 독자: 대표(코딩 초보)와 로컬 PC 개발 담당
> 짝 문서: `261002_[대표용 2쪽 요약] 무료 도장 만들기 도구 설계서.md`(같은 폴더) · 근거 파일은 표의 마지막 칸에 적었다.

## 대표께 먼저 드리는 3줄

1. **무엇** — 이름을 넣으면 도장 그림(배경이 비치는 PNG)이 바로 만들어지는 무료 도구를, 지금 무료 도구들과 같은 방식(서버 없이 브라우저 안에서만 도는 웹 페이지 한 장)으로 만드는 설계입니다.
2. **결론** — 만들 수 있고, 법으로 막힌 곳은 없습니다. 다만 ①인감·관공서 도장으로 오해하게 만드는 표현·기능을 넣지 않고 ②글꼴은 라이선스를 원문으로 확인한 7종만 쓰고 ③**이름이 서버로 한 글자도 가지 않도록 브라우저가 통신 자체를 막게 잠그는 것**까지 해야 합니다. 비교한 세 곳은 모두 이름을 서버로 보내고 있어서, ③이 우리의 가장 큰 차별점입니다.
3. **지금 위치와 다음 단계** — 이 문서는 「설계」까지이고, **도구는 아직 만들지 않았습니다**(운영 사이트도 그대로). 다음 순서는 ①로컬 PC로 가져와 보관·기록 → ②로컬 PC에서 이 문서 9장대로 개발 → ③시험 → ④대표 승인 뒤 홈페이지에 올리기(배포)입니다. 결정 11가지는 정해 두었고(2쪽 요약 ④), 가져오는 법은 저장소 맨 위 `로컬 반영 안내(대표용).md`에 있습니다.

## 1. 이 문서를 읽는 법과 낱말 풀이

이 문서는 앞(1~7장)이 「왜·무엇을」, 뒤(9장)가 「어떻게 만드나」입니다. 개발 담당은 9장만 보고 만들 수 있게 썼습니다. 처음 나오는 낱말은 여기서 먼저 풀어 둡니다.

| 낱말 | 한 줄 풀이 |
|---|---|
| 브라우저 | 크롬·엣지·사파리처럼 웹 페이지를 보여 주는 프로그램. 이 도구는 여기 안에서만 일한다 |
| 서버 | 홈페이지 파일을 보관했다가 보내 주는 회사 쪽 컴퓨터 |
| 정적 파일 | 서버가 누구에게나 똑같이 보내 주는 파일(HTML·그림·글꼴). 받는 사람마다 내용이 바뀌지 않는다 |
| PNG(투명) | 그림 파일 형식. 「투명」은 도장 바깥이 비어 있어 문서 위에 얹으면 글씨가 비쳐 보인다는 뜻 |
| 캔버스(Canvas) | 브라우저 안의 도화지. 자바스크립트로 그 위에 원·글자를 그린다 |
| 통신 금지 잠금(CSP) | 페이지가 「나는 어디로도 데이터를 보내지 않겠다」고 브라우저에 미리 선언하는 규칙. 선언을 어기는 요청은 브라우저가 막는다 |
| 글꼴 라이선스(OFL) | 글꼴을 무료로 쓰고 웹에 실어도 된다는 허락서. 단 글꼴 파일만 따로 팔면 안 된다 |
| 개발자 도구 Network 탭 | 브라우저에서 F12를 누르면 열리는 칸. 이 페이지가 바깥으로 보낸 요청이 한 줄씩 다 보인다 |

## 2. 무엇을 만드나

| 항목 | 정한 것 |
|---|---|
| 이름 | 디시전메이커 무료 도장 만들기 (홈페이지 안에서는 「무료 도장 만들기」) |
| 주소(예정) | `https://decisionmaker.ai.kr/tools/stamp-maker/` |
| 쓰는 사람 | 이력서·견적서·결재 문서 같은 일상 서류에 도장 그림을 넣어야 하는 개인·소상공인 |
| 하는 일 | 글자 입력 → 화면에서 바로 도장이 바뀜 → 그림 파일로 저장·복사 |
| 한 화면 | 입력·고르기·결과·저장이 스크롤 없이 한 화면(데스크톱 기준)에 다 보인다 |
| 하지 않는 일 | 인감 등록, 전자서명, 본인 확인, 서명 그리기, 회원가입, 광고, 기관 직인 흉내 |

**우리 제품 설명서에서 뽑은 화면 순서** — 「결과가 먼저 보이고, 손잡이는 그 옆에 모여 있다」. 접속하자마자 가상의 이름(홍길동)으로 된 도장이 이미 찍혀 있고, 그 아래에 저장 단추가 있으며, 글자 칸은 도장 옆에 있습니다. 사용자는 글자만 바꾸면 끝이고, 나머지는 고르고 싶을 때만 만집니다. 화면 순서는 경쟁 사이트가 아니라 이 원칙에서 뽑았고, 다 쓴 뒤 3장의 관찰 메모와 대조했습니다(3-5절).

### 3-4. 우리에게 남은 빈자리

1. **세 곳 모두 이름이 서버로 간다.** 이름이 기기 밖으로 한 번도 나가지 않고, 그걸 사용자가 직접 확인할 수 있는 도장 도구는 비교 대상 중 없었다.
2. 입력과 결과가 처음부터 한 화면에 같이 있는 구성은 없었다.
3. 동의·회원·광고가 모두 없는 곳은 없었다.
4. 문서에 넣었을 때 **실제 도장 크기(밀리미터)로 바로 들어가는** 그림 파일을 주는 곳은 확인되지 않았다(9-9절 — 우리가 더하는 것).

## 4. 법 검토

> 모든 조문은 2026-10-02 law.go.kr에서 원문을 열어 확인한 것만 적었습니다. 원문 전체는 `점검/법령_원문_확인.md`에 있습니다. 다른 AI 조사에 있던 조문 번호는 전부 다시 열어 봤습니다. **이 절은 법률 자문이 아닙니다** — 무료 도구이고 고지문이 사실만 적은 짧은 안내라서, 변호사 검토는 생략하고 문장을 보수적으로 쓰기로 정했습니다(2쪽 요약 결정 3).

### 4-1. 결론 (문장으로)

- **도장 그림을 만들어 주는 것 자체를 금지하는 조문은 찾지 못했습니다.** 형법이 벌하는 것은 「행사할 목적으로 남의 도장·서명을 위조하거나 함부로 쓰는 것」이고, 그 목적과 행위는 사용자에게 있습니다.
- 그래도 도구가 **나쁜 쓰임을 부추기는 모양**이 되면 안 됩니다. 그래서 관공서 도장(공인)처럼 보이게 하는 기능·문구는 넣지 않고, 기관 이름 입력은 막습니다(4-3절).
- **인감은 행정청에 신고한 도장**이라, 우리 그림 파일은 인감이 될 수 없습니다. 「인감」이라는 말을 홍보에 쓰지 않습니다.
- 개인정보 보호법은 「개인정보를 처리하는 자」에게 의무를 지웁니다. 이름은 개인정보이지만, **우리 서버가 이름을 받지도 남기지도 않으면** 우리는 그 이름을 수집하지 않습니다 — 5장의 설계가 그것을 보장합니다. 다만 홈페이지 개인정보처리방침에는 지금 「브라우저 안에서만 계산하는 도구 7가지」 목록이 있으므로(2026-10-02 확인), 도구를 올릴 때 그 목록에 도장 도구를 더해 8가지로 고칩니다.
- 글꼴은 저작권으로 보호되는 프로그램이므로, 라이선스를 원문으로 확인한 것만 씁니다(6장).

도구 페이지에는 방문 분석·광고·채팅 상담 코드를 **하나도 넣지 않습니다.** 이런 코드는 제3자 서버로 요청을 보내고, 페이지 안 글자를 읽을 수 있는 권한을 가집니다. 방문자 수는 서버의 접속 기록(어느 파일이 몇 번 열렸나 — 이름 없음)으로만 셉니다.

### 5-5. 통신 금지 잠금 (설계의 핵심)

`index.html`의 `<head>` 맨 앞쪽(어떤 스크립트보다 먼저)에 아래 규칙을 넣습니다. 브라우저는 이 규칙을 어기는 요청을 실행하지 않고 막습니다. 코드에 실수가 있거나 누가 나중에 분석 코드를 끼워 넣어도, 이 줄이 있는 한 바깥으로 데이터를 보낼 수 없습니다.

```html
<meta http-equiv="Content-Security-Policy"
      content="default-src 'none'; script-src 'self'; style-src 'self'; font-src 'self';
               img-src 'self' data: blob:; connect-src 'none'; form-action 'none';
               base-uri 'none'; object-src 'none'; frame-src 'none'; worker-src 'none'; manifest-src 'self'">
```

| 손잡이 | 무엇을 정하나 |
|---|---|
| `connect-src 'none'` | 자바스크립트가 서버와 주고받는 모든 통로(fetch·XHR·sendBeacon·WebSocket)를 막는다 |
| `form-action 'none'` | 입력 양식을 서버로 제출하는 길을 막는다 |
| `script-src 'self'` | 우리 서버의 JS 파일만 실행. 남의 스크립트·인라인 스크립트 금지 |
| `font-src 'self'` · `style-src 'self'` | 글꼴·스타일도 우리 서버 것만 → 외부 글꼴 서버로 가는 요청 0 |
| `img-src 'self' data: blob:` | 미리보기·내려받기용 그림은 기기 안에서 만든 것만 |

덧붙여 글자 칸에는 `autocomplete="off" spellcheck="false" translate="no"`를 붙입니다. 일부 브라우저의 「향상된 맞춤법 검사」·자동 번역은 입력한 글을 그 회사 서버로 보낼 수 있기 때문입니다.

**뜻풀이** — OFL은 「쓰고, 웹에 싣고, 고쳐 쓰고, 프로그램과 함께 나눠 줘도 되지만 글꼴 파일만 따로 팔면 안 되고, 라이선스 글을 함께 둬야 한다」는 허락입니다. 라이선스 원문 5항은 이 글꼴로 만든 **문서(우리 경우 도장 그림)에는 이 조건이 적용되지 않는다**고 밝힙니다 — 사용자가 만든 PNG는 자유롭게 써도 됩니다.

**예약 이름 주의** — OFL 3항: 글꼴을 고친 판(필요한 글자만 남겨 줄인 판 포함)은 예약된 이름을 쓸 수 없습니다. 나눔 계열과 Noto Sans KR('Source')을 줄여서 실을 때는 **글꼴 이름을 바꿔** 싣습니다(예: `DM Stamp Myeongjo`). 화면에 보이는 글씨체 이름은 「나눔명조 바탕(수정판)」처럼 원작을 밝히는 수준으로 적습니다(OFL 4항 — 원작자 이름으로 홍보하지 않는다).

**한자** — 한자 이름은 1·2번 글꼴에서만 만들 수 있습니다. 한자가 섞이면 견본판에서 3~7번은 「한자 없음」으로 흐리게 표시합니다.

**글자 수가 적은 글꼴(6·7번)** — 자주 안 쓰는 한글(예: 「똠」 「뷁」)이 이름에 있으면 그 글꼴은 흐리게 표시합니다. 어떤 글자가 있는지는 빌드 때 만든 목록(9-7절)으로 판단합니다.

## 8. 수익과 연결 — 무료 도구가 돈이 되는 길

무료 도구는 그 자체로 돈을 받지 않습니다. 대신 **사람을 데려오고, 믿음을 쌓고, 유료 제품으로 이어 주는 입구**가 됩니다. 아래 수치 예측은 하지 않았습니다(근거 없는 수치는 쓰지 않는다 — 표시광고법·회사 규칙).

| # | 방안 | 무엇을 하나 | 왜 돈과 이어지나 | 확인할 것 |
|---|---|---|---|---|
| 1 | 검색 입구 | 페이지 제목·설명을 「무료 도장 만들기 · 이름이 서버로 가지 않는」 축으로 쓴다 | 도장 검색은 서류 일을 하는 사람이 한다 = 우리 유료 제품의 고객층 | 검색량은 로컬에서 네이버 검색광고 키워드 도구로 확인(미확인) |
| 2 | 결과 바로 아래 한 줄 이어 주기 | 「서류를 한글(HWPX)로 바꿔야 하나요? → 슬라이드 메이커」 링크 1줄 | 도장을 찍는 사람은 PDF·한글 서류를 다루는 중이다 — 슬라이드 메이커의 PDF→HWPX 변환(유료, 건당)과 맞닿는다 | 링크는 이름을 싣지 않는 고정 주소(`?from=stamp-maker`만) |
| 3 | 「직접 확인하는 무저장」을 회사 신뢰 자산으로 | 5-6절 절차를 도구 아래 「확인하는 법」으로 공개 | 확인 가능한 약속은 다른 도구·유료 제품에도 옮겨 붙는 신뢰가 된다 | 시험 통과 뒤에만 게시 |
| 4 | 광고를 넣지 않는다 | 도구 페이지 광고 0 | 광고 수입은 잃지만, 광고 코드는 제3자 요청이라 3번의 약속을 깬다. 비교한 사이트 하나는 광고 코드가 있었다 → 이것이 차별점 | 결정됨(2쪽 요약 결정 4) |
| 5 | 다음 판 후보(v2) | 「PDF에 도장 찍기」 — 역시 브라우저 안에서만 | 도장 그림을 만든 사람의 다음 일은 서류에 찍는 것이다. 무료로 두면 체류·재방문이, 대량 처리를 유료로 두면 매출이 생긴다 | v1 반응을 본 뒤 별도 설계 |
| 6 | 홈 화면 설치 | 다른 도구처럼 앱 설치 지원(v1.1) | 즐겨찾기보다 재방문이 쉽다 | 서비스 워커를 쓰면 5-5절 잠금 문구를 함께 고친다 |

## 9. 자기완결 구현 장 — 이 장만 보고 만든다

### 9-1. 기술 기본안과 선택지

| 안 | 내용 | 판정 |
|---|---|---|
| **기본안** | 정적 HTML 1장 + CSS 1개 + 자바스크립트 모듈(ES Modules) 여러 개, 프레임워크·빌드 도구 없이 | **채택** — 우리 무료 도구들과 같은 방식, 서버 불필요, 파일만 올리면 끝. 다만 기존 도구는 한 파일에 다 넣었는데, 이번에는 기능별로 파일을 나눈다(고치기 쉽고 시험하기 쉽다) |
| 선택지 A | 기존 도구처럼 HTML 한 파일에 모두 | 가능. 잠금(5-5절)의 `script-src 'self'`가 인라인 스크립트를 막으므로, 이 안을 고르면 잠금 문구에 스크립트 해시를 넣어야 해 손이 더 간다 |
| 선택지 B | React·Next.js 등 | 채택 안 함 — 다른 AI 조사가 권했지만 빌드가 필요하고, 결과 파일이 커지며, 우리 도구들과 방식이 달라진다 |
| 선택지 C | SVG로 그리기 | 채택 안 함(v1) — 글꼴을 그림 안에 담으려면 글자를 선으로 바꾸는 별도 라이브러리가 필요. 인쇄용 벡터가 필요해지면 v2에서 검토 |

### 9-3. 모듈 구조 — 누가 누구를 부르나

```
main.js ─┬─ state.js ◀── ui.js (화면에서 바뀐 값을 넣는다)
         │      │
         │      ▼ 바뀜 알림
         ├─ input-rules.js ──▶ layout.js ──▶ render.js ──▶ texture.js
         │                                     ▲
         ├─ fonts.js ── fonts-coverage.js ─────┘ (글꼴 준비되면 다시 그림)
         └─ export.js ◀── ui.js (저장·복사·공유 단추)
```

| 모듈 | 받는 것 | 내는 것 | 지켜야 할 것 |
|---|---|---|---|
| input-rules | 사용자가 친 글자 | `{text, chars[], script, warnings[], blocked, reason}` | 화면·통신에 손대지 않는 순수 함수 |
| layout | 글자 배열·모양·읽는 순서·캔버스 크기 | 칸 목록 `[{char, x, y, w, h}]` + 테두리 도형 | 순수 함수 — 같은 입력이면 같은 결과 |
| fonts | 글꼴 번호 | 준비 여부 · 글자 지원 여부 | 글꼴 요청은 시작할 때 한꺼번에만 |
| render | 칸 목록·글꼴·색·굵기·양각/음각·크기 | 캔버스 위 그림 | 크기를 바꿀 때 그림을 늘리지 말고 다시 그린다 |
| texture | 캔버스·세기·씨앗값 | 질감 입힌 캔버스 | 씨앗값은 페이지 열 때 무작위 1회 — 이름에서 만들지 않는다 |
| export | 캔버스·출력 크기·밀리미터 | Blob(PNG) · 파일 이름 | 통신 금지 — blob 주소만 쓴다 |

| 안내 목록 | 「인감」「관인」「직인」 → 만들되 「인감·관인은 관청에 신고한 실물 도장만 해당돼요」 안내 | `NOTICE_WORDS` |

`BLOCK_WORDS`(우리가 새로 정함 — 막기로 결정, 2쪽 요약 결정 2): 대한민국, 정부, 국회, 대법원, 법원, 검찰, 경찰, 국세청, 세무서, 시청, 구청, 군청, 도청, 교육청, 주민센터, 행정복지센터, 동사무소, 읍사무소, 면사무소, 우체국, 병무청, 장관, 시장인, 구청장, 군수, 도지사, 청장. 판단은 「입력 안에 그 낱말이 연속으로 들어 있나」(공백 제거 후)로 한다. **사람 이름과 겹칠 위험**(예: 이름에 「정부」가 들어가는 경우는 드물지만 0은 아님)이 있어 목록 고치기는 정지점 P2다.

### 9-6. 모양과 배치 규칙

캔버스 작업 크기 `S = 1024px`(정사각), 가운데 `(512, 512)`. 실제 저장 크기가 다르면 같은 계산을 그 크기로 다시 한다.

| 모양 | 바깥 도형 | 글자 영역(안쪽 여백 뺀 네모) |
|---|---|---|
| 원 | 반지름 `R = 0.46·S` | 원에 들어가는 정사각 — 한 변 `(R − 테두리 − 여백)·√2` |
| 세로 타원 | 가로 반지름 `0.36·S`, 세로 반지름 `0.46·S` | 타원 안 네모 — 가로 `(0.36·S − t − p)·√2`, 세로 `(0.46·S − t − p)·√2` |
| 네모 | 한 변 `0.90·S`, 모서리 둥글기 `0.04·S` | 한 변 `0.90·S − 2(t + p)` |

(t = 테두리 굵기, p = 안쪽 여백 `0.035·S`)

**글자 칸 나누기** — 「세로 칸(열)을 오른쪽부터 채우고, 한 열 안에서는 위에서 아래로」가 기본(전통 도장 읽는 순서). 「가로 읽기」를 고르면 왼쪽 위부터 줄 단위로.

| 글자 수 | 원 | 세로 타원 | 네모 |
|---|---|---|---|
| 1 | 가운데 1칸 | 1칸 | 1칸 |
| 2 | 세로 1열 2칸 | 세로 1열 2칸 | 세로 1열 2칸 |
| 3 | 세로 1열 3칸(글자를 가로로 넓혀 채움) | 세로 1열 3칸 | 오른쪽 열 2칸 + 왼쪽 열 1칸(왼쪽 칸은 세로로 길게) |
| 4 | 2열 × 2칸 | 2열 × 2칸 | 2열 × 2칸 |
| 5~16 | — | — | 열 수 `c = ceil(√n)`, 열마다 `ceil` 또는 `floor`(n/c)칸 — 남는 칸은 **왼쪽 열**이 덜 갖고, 그 열의 칸은 세로로 늘인다 |
| 영문·숫자만 | 가로 한 줄, 글자 영역 폭에 맞춰 줄임 | 같음 | 같음 |

**글자를 칸에 넣는 법** — 각 글자의 실제 윤곽을 잰 뒤(`measureText`의 `actualBoundingBox*` 값) 칸의 88%를 채우도록 가로·세로 배율을 따로 정한다. 단 가로/세로 배율 비가 `0.6 ~ 1.8`을 넘으면 그 안으로 자른다(글자가 너무 찌그러지지 않게). 윤곽의 가운데를 칸의 가운데에 맞춘다.

**새김** — 양각: 테두리와 글자를 잉크 색으로. 음각: 도형 안을 잉크로 채운 뒤 글자 자리를 지운다(`globalCompositeOperation = 'destination-out'`).

**두 줄 테두리** — 바깥 선 안쪽으로 `0.025·S` 띄워 가는 선(바깥 굵기의 45%)을 하나 더.

### 9-7. 글꼴 규칙

| 규칙 | 정한 것 |
|---|---|
| 파일 | 글꼴마다 woff2 한 개(도장용 굵기 한 벌). Noto 두 종은 한글 전체 + 자주 쓰는 한자 4,888 + 영문·숫자, 나머지는 그 글꼴에 있는 한글 전체 + 영문·숫자 |
| 받는 때 | 페이지를 열면 7개를 **정해진 순서로 한꺼번에** 요청(`FontFace` + `document.fonts.add`). 글자 입력·글씨체 클릭과 상관없다 |
| 준비 표시 | 「글꼴 n/7 준비됨」. 1번이 준비되면 바로 그리고, 나머지는 준비되는 대로 견본판에 나타남 |
| 실패 | 받기 실패한 글꼴은 견본판에서 「불러오지 못함 · 새로고침」으로 표시. 다른 글꼴로 계속 쓸 수 있다 |
| 화면 글자(UI) | 시스템 글꼴(`-apple-system, 'Malgun Gothic', sans-serif`)만 — 외부 글꼴 서버(jsdelivr 등) 요청 0 |
| 이름 바꾸기 | 줄인 판은 OFL 3항에 따라 새 이름(`DM Stamp …`)으로 저장, 원래 저작권 문구와 OFL 원문을 `fonts/LICENSES/`에 함께 둔다 |
| 없는 글자 목록 | `build/make-fonts.py`가 각 글꼴의 글자 표를 읽어 「한글 11,172자 중 없는 글자」를 `js/fonts-coverage.js`로 써 낸다(6·7번만 수천 자) |

`build/make-fonts.py`가 할 일(개발 PC에서 한 번):
1. Google Fonts 저장소에서 7종 원본(ttf)과 OFL.txt를 받는다.
2. 굵기가 바뀌는 글꼴(Noto 2종)은 굵기 900 한 벌로 고정한다(fontTools `instancer`).
3. 9-7절 「파일」 칸의 글자만 남겨 woff2로 저장한다(fontTools `subset`, `flavor='woff2'`).
4. 글꼴 이름표(name 표)의 이름을 `DM Stamp …`로 바꾼다.
5. 없는 글자 목록을 JS 파일로 쓴다.

### 9-8. 색·굵기·잉크 질감

| 손잡이 | 고를 수 있는 값 | 기본 |
|---|---|---|
| 잉크 색 | 인주 빨강 `#D0312D` · 진한 빨강 `#9E1B1B` · 남색 `#1F3A8A` · 검정 `#1B1B1B` | 인주 빨강 |
| 테두리 굵기 | 가늘게 3% · 보통 4.5% · 굵게 6% (S 대비) | 보통 |
| 잉크 질감 | 없음 · 약하게 · 옛 도장 | 약하게 |
| 투명도 | 잉크 불투명도 0.92(문서 글씨가 살짝 비쳐 실제 날인처럼) | 고정 |

잉크 질감: 씨앗값으로 돌리는 난수(mulberry32)로 작은 점을 `destination-out`으로 지운다. 「약하게」 = 점 900개·지름 `0.002~0.006·S`, 「옛 도장」 = 점 2,600개·지름 `0.002~0.012·S` + 테두리 바깥쪽 가장자리를 3곳 정도 끊김. 씨앗값은 페이지를 열 때 무작위로 1회 정하고 「질감 다시 섞기」 단추로만 바꾼다. **이름으로 씨앗을 만들지 않는다**(같은 이름이 늘 같은 무늬가 되면 그 무늬가 이름의 흔적이 된다).

### 9-9. 출력

| 항목 | 정한 것 |
|---|---|
| 형식 | PNG, 바깥 투명(알파) |
| 크기 고르기 | 실제 지름(또는 한 변) **12 · 15 · 18 · 24mm** 중 고름(기본 15mm) + 「큰 그림 1024px」 |
| 해상도 | 600dpi — 픽셀 = `round(mm × 600 ÷ 25.4)` → 12mm 283px · 15mm 354px · 18mm 425px · 24mm 567px |
| 실제 크기 정보 | PNG 안에 해상도 정보 덩어리(`pHYs`: 1미터당 23,622 픽셀)를 넣는다 → 해상도 정보를 읽는 문서 프로그램에서는 넣자마자 고른 밀리미터 크기로 들어간다(한글·워드에서 실제로 그런지는 로컬 확인 — 11장) |
| 만드는 법 | 저장할 크기로 캔버스를 **다시 그린 뒤** `toBlob('image/png')` → 바이트 배열의 첫 덩어리(IHDR) 바로 뒤에 `pHYs` 덩어리(길이 9 + CRC32)를 끼워 넣는다 |
| 파일 이름 | `도장_<모양>_<YYYYMMDD>.png` — 이름은 넣지 않는다 |
| 내려받기 | `URL.createObjectURL(blob)` + 보이지 않는 `<a download>` 클릭 → 1초 뒤 `revokeObjectURL` |
| 복사 | `navigator.clipboard.write([new ClipboardItem({'image/png': blob})])`. 안 되는 브라우저면 「이 브라우저는 그림 복사를 지원하지 않아요 — 저장을 써 주세요」. 복사본은 해상도 정보가 빠질 수 있어 「크기가 다르게 들어가면 저장한 파일을 쓰세요」를 함께 안내 |
| 공유 | `navigator.canShare({files})`가 참인 기기(주로 휴대폰)에서만 단추를 보인다. 공유는 사용자가 고른 앱으로 그림을 넘기는 일이며, 우리 서버는 거치지 않는다 |
