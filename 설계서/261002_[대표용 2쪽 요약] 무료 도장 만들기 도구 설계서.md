|---|---|---|---|---|

## ② 원문 핵심 한 줄씩

1. **벤치마킹** — 3곳(싸인오케이·스탬프NG·도뉴) 모두 접속됨(응답 200). **세 곳 모두 이름을 서버로 보낸다**(두 곳은 페이지 코드에서, 한 곳은 그 사이트 스스로의 안내에서 확인). 우리는 이 빈자리를 차지한다.
2. **법** — law.go.kr 원문 20개 조문 확인. 도장 그림 만들기를 막는 조문은 없음. 위조·부정사용은 사용자 목적의 문제이나, 우리는 관공서 이름을 막고 「인감·전자서명이 아니다」라고 알린다.
3. **개인정보** — 이름은 브라우저 안에서만 쓰이고, 페이지에 **통신 금지 잠금**을 걸어 브라우저가 바깥 전송을 막는다. 누구나 F12로 「요청 0건」을 확인하는 절차와 자동 시험까지 설계.
4. **글꼴** — 라이선스 원문(OFL)을 연 7종만. 한자 이름은 2종(Noto)만 가능. 글자 수를 실제로 세어 표로 남김.
5. **우리만의 것** — 실제 밀리미터 크기로 저장(문서에 넣자마자 도장 크기), 내 이름으로 보는 글씨체 견본판, 광고·회원·동의 없음.
6. **수익 연결** — 도장을 찍는 사람은 서류 일을 하는 사람 → 결과 아래 「PDF→한글 변환(슬라이드 메이커)」 한 줄 연결. 광고는 넣지 않는다(무저장 약속과 충돌).
7. **홈페이지** — 도장 카드 4번째, 룰렛부터 한 칸씩 뒤로, 「NEW · 무료」 삭제, 카드별 색 + 오른쪽 아래 둥근 기능키. 그림 없이 CSS만(미리보기 그림 있음).

## ③ 🔴 대표 생각 중 고쳐 드릴 것

| 대표 생각(원문) | 고쳐 드릴 점 |
|---|---|
| 「사이트들을 벤치마킹해서 … 만들고 싶어」 | 기능·순서 같은 **원리**만 가져왔고, 화면 순서는 우리 원칙에서 새로 뽑았습니다. 비교 사이트 한 곳은 단계별 넘김, 한 곳은 결과 목록형인데, 우리는 「결과가 먼저 보이는 한 화면」입니다 — 베꼈다는 말이 나올 여지를 줄였습니다(15자 대조 0건). |
| 「개인정보보호법 관련 이슈를 원천 차단」 | 우리 쪽 서버는 원천 차단됩니다. 다만 **사용자 브라우저 자체의 기능**(맞춤법 검사·자동 번역 등)은 우리가 완전히 통제할 수 없어, 입력 칸에서 그런 기능을 끄는 표시를 넣는 데까지가 할 수 있는 최선입니다. |
| 「필요하면 힉스필드로 카드 꾸미기」 | 힉스필드 잔액이 **0 크레딧**이라 만들지 않았습니다. CSS만으로 충분히 달라 보이게 했습니다. |
| 다른 AI 조사의 「스탬프NG는 이름을 서버에 안 보낸다」 | **사실과 다릅니다** — 그 사이트 스스로 「생성을 위해 잠깐 보낸다」고 안내합니다. 기록에 남기지 않을 뿐 전송은 합니다. |

## ⑤ 대표가 직접 확인하셔야 할 것

| 무엇 | 왜 우리가 못 했나 | 어떻게 |
|---|---|---|
| 유튜브 쇼츠 내용 | 클라우드는 영상을 못 보고, 3줄 요약 칸이 비어 있었다 | 보시고 `자료/유튜브_쇼츠_요약.md` 3줄 채우기 → 다음 판 반영 |
| 15mm로 저장한 도장이 한글·워드에 실제 15mm로 들어가는지 | 클라우드에 한글·워드가 없다 | 로컬 개발 5단계 뒤 넣어 보고 자로 재기 |
| 7종 글꼴의 실제 도장 모양 | 클라우드에서 화면 비교를 하지 않았다 | 로컬 개발 4단계 견본판으로 |
| 「무료 도장 만들기」 검색량 | 검색광고 도구는 로그인 필요 | 네이버 검색광고 → 키워드 도구 |
| 고지문의 법적 충분성 | 법률 자문이 아니다 | 결정 3 — 변호사(또는 대한법률구조공단 132) |

## ⑥ 가장 큰 위험 셋

| 위험 | 막는 법 |
|---|---|
| 1. 누군가 이 도구로 남의 도장을 만들어 서류를 위조 | 막을 수는 없다 — 관공서 이름 차단·「인감 아님」 안내·고지문으로 **부추기지 않음**을 보이고, 인감·직인 홍보 문구를 쓰지 않는다 |
| 2. 「서버로 안 보낸다」고 써 놓고 실제로 무언가 나가는 경우(나중에 누가 코드를 넣는 등) | 통신 금지 잠금 + 요청 0건 자동 시험이 통과할 때만 문구 게시(정지점 P3). 실패하면 배포 중지 |
| 3. 글꼴 라이선스 위반 | 원문 확인한 7종만, 줄인 판은 이름 바꾸기, 라이선스 원문 동봉(OFL 2·3항) |
