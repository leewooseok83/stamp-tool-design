## 3. 반드시 지킬 규칙

먼저 **`규칙/회사 규칙 발췌.md`를 처음부터 끝까지 읽는다.** 회사 규칙(CLAUDE.md)에서 이 과업에 걸리는 절을 그대로 옮긴 것이다. 핵심만 7줄로 줄이면:

1. **벤치마킹 3단(§3-3-1)** — 기능·발상·순서는 가져오되 **표현은 베끼지 않는다.** 문장·소제목 번역이나 어순 바꾸기 금지. **한 화면에서 같은 요소를 3개 이상 같은 순서로 배치 금지.** **참고 화면을 띄워 놓고 만들지 않는다**(보고, 닫고, 메모만 보고 만든다). 끝에 **공백 제거 15자 연속 일치 0건**을 기계로 확인한다.
2. **출처 F70(§3-4)** — 인용할 URL은 **실제로 열어 대조**한다. 접속 실패(403·404·시간 초과)도 **그대로 기록**하고 누가 어떻게 확인할지 적는다. 법 조문은 **law.go.kr 원문**만 근거로 한다. `자료/`의 다른 AI 조사 결과는 **단서이지 근거가 아니다** — 그 안의 조문 번호·경쟁사 기능 서술은 전부 원문으로 다시 확인한다. 법 검토에서 볼 후보: 개인정보보호법 · 형법(공인·사인 위조와 부정사용, 사문서 위조·행사) · 인감증명법 · 전자서명법 · 저작권법(글꼴·프로그램) · 상표법(기관·기업 표장). 조문 번호는 **원문에서 확인한 것만** 적는다.
3. **ADMS화 4기준(§3-3)** — ①표현 미복사 ②버린 것·이유·잃은 것 ③더한 것·없으면 어떻게 나빠지나 ④`축적층.md`. 못 채우면 「ADMS화」라고 부르지 않는다.
4. **개인정보 서버 무저장** — 브라우저 안에서만 처리 · 서버 전송 0 · 저장 0. **설계로 증명**한다(§2 필수 구성 6). 이름이 서버를 거치는 안은 아예 내지 않는다.
5. **콘텐츠 절대 금지선 6종(§3-1)** — 정치 · 음란 · 욕설 · 비방 · 모욕 · 격투. 카드 그림·예시 이름·문구에도 적용. 예시 이름은 「홍길동」 같은 가상 이름만.
6. **초보자 글쓰기(§1-2)** — 3줄 요약이 먼저, 용어는 첫 등장 전에 풀이, 수치는 표, 경로는 표의 마지막 칸. 「프로그래밍적 표현」은 「무엇을 정하는 손잡이인가」로 바꿔 쓴다.
7. **결과를 먼저 파일로 저장하고 보고한다.** 산출물 하나가 끝날 때마다 `git add -A && git commit`. 세션이 끊겨도 커밋된 것은 남는다. 채팅에만 적고 파일에 없는 내용은 사라진 것으로 친다.

- **이름 표기** — 제품명은 언제나 회사명을 붙여 「디시전메이커 무료 도장 만들기」처럼 쓴다. 홈페이지 안에서는 「무료 도장 만들기」.
- **우리 제품 설명서에서 화면을 뽑는다** — 화면 순서는 경쟁사가 아니라 §2 필수 구성 9의 요구에서 뽑고, 초안을 먼저 쓴 뒤 나중에 경쟁사와 대조한다.

## 5. 클라우드 세션이 못 하는 것과 그 처리

| 못 하는 것 | 처리 |
|---|---|
| 한글(hwpx)·PDF 변환, 한글 프로그램 | md만 만든다. pdf·hwpx는 로컬 PC에서 조율자가 `문서세트.py`로 만든다(회사 규칙 §1 — 모든 문서는 md+pdf+hwpx) |
| 파워포인트 | 쓰지 않는다 |
| 유튜브 영상 시청 | `자료/유튜브_쇼츠_요약.md`의 제목·채널과 **대표가 적어 주신 3줄**만 근거로 쓴다. 비어 있으면 「영상 내용 미확인」 |
| 대표 로컬 PC·회사 폴더 | 이 저장소 안의 파일이 전부다. 규칙 발췌 안의 `10. …\`, `4. …\` 같은 경로는 열 수 없고 「근거가 거기 있다」는 뜻만 안다 |
| 한글 글꼴의 실제 모양 확인 | 글꼴 후보·라이선스까지만. 모양 비교는 로컬에서 |
| 바깥 사이트 접속 | 환경 설정의 Network access 가 Custom 이고 도메인이 허용돼야 열린다. 안 열리면 응답 코드와 함께 「확인 실패」로 적고 넘어간다(멈추지 않는다) |
| 운영 사이트 배포·수정 | 하지 않는다. 개선안 파일까지만 |

## 6. 끝낼 때

1. 모든 파일이 커밋돼 있는지 `git status`로 확인 → 가지(branch)에 **푸시**한다(세션이 만든 가지 이름 그대로). 가능하면 PR(Pull Request)을 연다.
2. 마지막 채팅 보고는 한국어로 짧게: ①만든 파일 표(이름·줄 수) ②15자 대조 결과(건수) ③「확인 못 함」 목록 ④쓴 비용(토큰·크레딧, 아는 범위에서) ⑤대표가 할 일 3줄.
3. 세션이 중간에 멈춰도(크레딧 소진 등) 커밋된 것까지는 남는다 — 그래서 §3 ⑦이다.
