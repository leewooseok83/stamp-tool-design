# 홈페이지 무료 도구 칸 개선안 — 무엇을 왜 바꿨나

> 2026-10-02 클라우드 세션 · 운영 사이트는 건드리지 않았다. 아래 파일을 로컬 PC에서 붙여 넣고 배포하는 것은 대표 승인 뒤의 일이다.

## 대표께 먼저 드리는 3줄

1. **무엇** — 도장 카드를 4번째에 넣고(메뉴 룰렛은 바로 오른쪽으로), 「NEW · 무료」 배지를 지우고, 카드마다 색과 오른쪽 아래 둥근 기능키를 달았습니다.
2. **결론** — 그림 파일 없이 CSS만으로 됩니다. 힉스필드는 잔액이 0이라 쓰지 않았고, 쓰지 않아도 충분히 달라 보입니다(미리보기 그림 2장).
3. **진행** — 카드 꾸밈은 도장 카드를 뺀 판으로 **먼저** 붙이고(대표 결정 2026-10-02), 도장 카드는 도구가 완성되면 붙입니다. 홈페이지에 실제로 붙이는 일(배포)은 로컬 PC에서 대표 승인 뒤에 합니다. 순서는 4절.

| 파일 | 무엇 |
|---|---|
| `개선안_index_무료도구구역_도장카드제외.html` | **1차 적용판(지금)** — 운영 index.html **234~314행**을 바꿔 끼울 조각. 도장 카드 없이 8장 꾸밈만 |
| `개선안_index_무료도구구역.html` | **2차 적용판(도장 도구 공개 때)** — 같은 자리에 바꿔 끼울 조각. 도장 카드 포함 9장 |
| `개선안_style_추가.css` | 운영 style.css **맨 끝에 덧붙일** 규칙(기존 줄 삭제 없음) |

## 2. 왜 이렇게 했나

### 2-1. 디자인의 출처
카드 색 띠·아이콘 타일·점무늬·알약 단추는 모두 홈페이지에 이미 있는 색 체계(남색·금색·초록·하늘색 변수)와 모서리 둥글기(18px)에 맞춰 새로 그렸다. 다른 사이트 화면을 보고 만들지 않았다.

### 2-2. 읽힘(글자 대비)
기능키 글자가 바탕색 위에서 잘 읽히는지 계산했다(웹 접근성 기준 4.5:1 이상). 처음 고른 주황·청록이 기준에 못 미쳐 조금 진하게 바꿨다. 노랑·금색 단추는 흰 글자가 안 읽혀 진한 남색 글자를 쓴다.

| 카드 | 단추 색 | 글자 | 대비 |
|---|---|---|---|
| 반응속도 | #E0A11B | 남색 | 7.16 |
| 가리기 | #0E6F52 | 흰색 | 6.15 |
| 글자수 | #2F6FB5 | 흰색 | 5.17 |
| 도장 | #C23A2E | 흰색 | 5.33 |
| 룰렛 | #B9541D | 흰색 | 4.83 |
| 뽑기 | #6B4FC8 | 흰색 | 5.87 |
| 전월세 | #0F7372 | 흰색 | 5.65 |
| 저울 | #1F3A8A | 흰색 | 10.34 |
| 솔로몬 | #B98A16 | 남색 | 5.17 |

### 2-3. 솔로몬의 「AI」 표시를 남긴 이유
「NEW」와 「무료」는 정보가 없어서 지웠지만, 「AI」는 **사연이 AI 서버로 간다**는 사실을 미리 알리는 구실을 한다. 다른 8개 도구는 서버로 아무것도 보내지 않으니, 이 표시가 없으면 방문자가 같은 줄 알 수 있다. 그래서 오른쪽 위에 작은 「AI 사용」만 남겼다.

### 2-4. 다른 구역은 안 바뀐다
새 규칙은 모두 `.products .tool-card` 안에서만 효과가 있다. 유료 카드(`.p-card`)·가격표는 같은 `card-icon` 이름을 쓰지만 영향받지 않는다. 기존 `.badge` 규칙도 지우지 않았다.

## 5. 덤으로 발견한 것 (판단은 대표께)

- 글자수 세기 등 기존 무료 도구는 Pretendard 글꼴을 **jsdelivr의 「동적 분할본」**으로 불러온다(2026-10-02 페이지 코드에서 확인). 이 방식은 화면에 나온 글자에 따라 글꼴 조각 파일을 받아 오므로, 입력한 글이 많으면 jsdelivr 쪽 기록에 「어느 글자 구역 조각을 받았나」 정도의 흔적이 생긴다. 내용이 그대로 가는 것은 아니어서 지금 안내문이 틀렸다고 보기는 어렵지만, 「서버로 오지 않는다」를 더 단단히 하려면 입력 칸만 시스템 글꼴로 바꾸는 방법이 있다. 도장 도구는 처음부터 그렇게 설계했다(설계서 5-2절).
