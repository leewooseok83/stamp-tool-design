## 2. 요구 정리 (요약 표)

| # | 요구 | 지금 상태(현재_index_무료도구구역.html 기준) | 개선안에서 할 것 |
|---|---|---|---|
| 1 | 도장 도구를 **4번째 칸**에 넣는다 | 카드 8장. 4번째 = 「오늘 뭐 먹지? 메뉴 룰렛」(원본 267~275행) | 4번째에 「무료 도장 만들기」 카드 추가 → 카드 9장 |
| 2 | 「오늘 뭐 먹지?」는 **바로 오른쪽**으로, 그 뒤는 **순차로 밀림** | 순서: 반응속도 → 신분증 가리기 → 글자수 세기 → 메뉴 룰렛 → 뽑기 비용 → 전세vs월세 → 결정 저울 → 솔로몬의 심판 | 반응속도 → 신분증 가리기 → 글자수 세기 → **도장** → 메뉴 룰렛 → 뽑기 비용 → 전세vs월세 → 결정 저울 → 솔로몬의 심판 (기존 순서 유지, 하나만 끼움) |
| 3 | 「NEW · 무료」 배지 **삭제** | 카드 8장 전부 `<span class="badge badge-live mono">NEW · 무료</span>` (솔로몬은 「NEW · 무료 · AI」) | 배지 줄 삭제. 단 솔로몬의 「AI」 표시는 **AI 서버 전송을 알리는 구실**이 있으므로 어떻게 남길지 안을 낸다(머리글·cards-note 문단에서 이미 「전부 무료」를 말하고 있다) |
| 4 | 이동 단추를 **각 카드 우측 하단의 예쁜 기능키**로 | `.card-go`가 글 바로 아래 왼쪽에 작은 글씨(「측정하러 가기 →」 등 8종) | 카드 안에서 우측 하단 고정 · 단추 모양(테두리·배경·호버) · 8~9장 **같은 형식** · 글귀는 유지하거나 짧게 |
| 5 | 카드가 **단조롭다** → 카드별 디자인 | 카드 8장이 흰 바탕·초록 선 아이콘·같은 틀 | 카드마다 성격이 보이는 꾸밈(색 띠·배경 무늬·아이콘 크기 등) — **우리 디자인**이어야 하고(§3-3-1), 모바일(1024px 이하 한 줄)에서도 깨지지 않아야 한다 |
| 6 | 필요하면 **힉스필드·무료 사이트**로 카드 그림 | 그림 없음(SVG 선 아이콘만) | 가능하면 카드 그림 시안을 만들어 `그림/`에 두고, 쓴 도구·비용·프롬프트를 기록. 그림 없이도 되는 안(CSS만)을 **기본안**으로 둔다 |

## 4. 지키는 것

- **운영 사이트는 바꾸지 않는다.** 배포(대외 발행)는 대표 승인 뒤 로컬 PC에서 한다.
- 도장 도구 카드의 링크는 아직 없는 도구이므로 `href="tools/stamp-maker/"`처럼 **예정 주소**로 두고 설명에 「도구 완성 뒤 연결」이라고 적는다. 「준비 중」 표시 방안도 안으로 낸다.
- cards-note 문단의 「솔로몬의 심판을 뺀 7가지는 … 서버로 오지 않습니다」는 도장 도구가 들어가면 **8가지**가 된다 — 숫자를 함께 고친다(도장 도구도 브라우저 안에서만 처리하므로).
- 콘텐츠 금지선 6종(정치·음란·욕설·비방·모욕·격투)은 카드 그림·문구에도 적용.
