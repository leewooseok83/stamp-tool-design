# 벤치마킹 사이트 3곳 — 접속은 클라우드 세션에서 한다

> 대표가 주신 참고 사이트(D164 원문 2)~4)). 이 로컬 세션에서는 **열지 않았다** — 접속·관찰은 클라우드 세션의 일이다.
> 접속하려면 환경 설정의 Network access 가 Custom 이고 아래 도메인이 허용돼 있어야 한다(「클라우드 세션 시작 안내(대표용).md」 ④).

|---|---|---|---|---|
| 2 | 싸인오케이 | https://www.signok.com/practiceSign.sg | 전자계약 서비스 안의 무료 서명·도장 만들기 | `signok.com` `www.signok.com` |
| 3 | 스탬프NG | https://stampng.com/ | 이름→모양→글씨체→투명 PNG 무료 도장 생성(비회원) | `stampng.com` |

「무엇을 하는 곳인가」 칸은 `260919_챗GPT 조사 결과.txt`·`260919_구글 제미나이 조사 결과.txt`에 적힌 것을 옮긴 것이며 **직접 확인한 사실이 아니다.** 클라우드 세션이 열어서 확인한 뒤 고쳐 적는다.

## 사이트마다 기록할 것 (설계서 「벤치마킹 관찰」 절에 표로)

| 칸 | 적을 것 |
|---|---|
| 접속 결과 | 날짜·시각, 응답 코드(200/403/404/시간 초과 등). **실패도 그대로 적는다**(F70 ③) |
| 기능 목록 | 입력(이름·상호·문구), 모양, 글씨체 수, 색, 크기, 출력 형식(PNG 투명 여부·크기), 복사·공유 단추 |
| 입력에서 결과까지 단계 수 | 사용자가 누르는 횟수 |
| 개인정보 안내 | 이름을 서버로 보내는지, 저장하는지에 대해 **그 사이트가 뭐라고 밝히는지**(밝힌 글이 없으면 「안내 없음」) |
| 광고·회원가입 | 있음/없음 |
| 법적 고지 | 인감 효력·위조 금지 문구 유무 |
| 좋은 점 / 아쉬운 점 | 각 2~3개 — **원리만** 적는다. 문구·배치·아이콘은 적지 않는다 |

## 반드시 지킬 것 (규칙/회사 규칙 발췌.md §3-3-1)

- 보고 나서 **창을 닫고, 메모만 보고** 우리 화면을 설계한다. 참고 화면을 띄워 놓고 만들지 않는다.
- 한 화면에서 **같은 요소를 3개 이상 같은 순서로** 배치하지 않는다.
- 문장·소제목을 번역하거나 어순만 바꿔 쓰지 않는다. 비교표의 항목 구성·순서를 그대로 옮기지 않는다.
- **15자 대조용 원문 저장**: 각 사이트의 글(본문 텍스트)을 `점검/원문_signok.txt` `점검/원문_stampng.txt` `점검/원문_donue.txt`로 저장해 두고, 설계서·홈페이지 개선안을 다 쓴 뒤 공백을 지우고 15자 연속 일치를 기계로 대조한다 → `점검/15자_대조_결과.md`. 1건이라도 나오면 다시 쓴다. 이 원문 파일은 **내부 조사용**이며 대외 산출물에 한 글자도 싣지 않는다.
- 경쟁사 화면 캡처 그림은 저장하지 않는다(화면 배치는 화상디자인으로 보호될 수 있다 — §3-3-1 ③).
