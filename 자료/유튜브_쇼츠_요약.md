# 유튜브 쇼츠 — 대표가 참고하라고 주신 영상 (1번 자료)

> 주소: https://youtube.com/shorts/5ceatfjPLVs (대표 원문의 `?si=…` 꼬리는 공유 추적용이라 뺐다)
> 2026-10-02 로컬 세션에서 **제목·채널만** 유튜브 공개 정보(oEmbed)로 가져왔다.
> **영상 내용(화면·음성)은 보지 못했다.** 클라우드 세션도 유튜브 영상을 볼 수 없다(INDEX F404 ①).
> 그래서 영상의 내용은 **아래 「대표가 적어 주신 3줄」만을 근거로** 쓴다. 비어 있으면 「영상 내용 미확인」으로 적고 설계 판단에서 뺀다.

| 항목 | 값 | 어떻게 확인했나 |
|---|---|---|
| 제목 | 한글 도장 이미지 삽입하는 방법 투명 PNG 직인 만들기! | oEmbed `title` |
| 채널 | 천안제일사무기 | oEmbed `author_name` |
| 채널 주소 | https://www.youtube.com/@천안제일사무기 | oEmbed `author_url` |
| 미리보기 그림 | https://i.ytimg.com/vi/5ceatfjPLVs/hq2.jpg | oEmbed `thumbnail_url` |
| 설명글 | 가져오지 못함 | 영상 페이지 본문이 스크립트로만 채워져 글이 안 잡힘 |
| 올린 날짜·조회수 | 가져오지 못함 | 위와 같음 |
| 영상 내용 | **보지 못함** | 영상 재생·자막 읽기 불가 |

제목으로 미루어 「만든 도장 PNG를 한글(hwp) 문서에 넣는 방법」을 보여 주는 짧은 안내 영상으로 보이나, 이것은 **추측**이다.

다른 AI 조사(같은 폴더)가 이 영상에 대해 적은 것 — **셋이 서로 다르고, 어느 것도 검증되지 않았다**:

| 조사 | 영상에 대해 적은 것 | 믿을 수 있나 |
|---|---|---|
| 챗GPT | 「현재 링크의 영상 내용을 직접 판독하지 못함 · 판단에서 제외」 | 정직한 「미확인」 |
| 제미나이 | 「유튜브 영상에 소개된 스탬프NG … 광고가 많아」 | 근거(장면·대사) 없음 |
| 젠스파크 | 「도장 이미지를 투명 PNG로 만들어 한글 문서에 삽입하는 실사용 가이드 영상 · 한글에서 글자처럼 취급 해제 → 글 앞으로 → 크기 조절 실전 팁 · 영상에서도 지적된 광고 과다」 | 가장 구체적이나 본 것인지 추측인지 알 수 없음 |

제목·채널(사무기기 판매점)과 젠스파크의 서술이 서로 맞아떨어지므로 「한글 문서에 도장 PNG를 넣는 방법 안내」일 **가능성이 높다**고만 적고, 설계 근거로는 대표의 3줄만 쓴다.
