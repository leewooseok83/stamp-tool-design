1️⃣ 법적 검토 — 무료 도장 만들기 웹사이트, 문제 없는가?

결론부터: “이름 입력 → 원형 도장 이미지 → 투명 PNG 다운로드” 서비스 자체는 국내에서 이미 수십 곳이 운영할 만큼 합법적 영역입니다. 다만 아래 5개 리스크 항목의 설계적 방어가 필요합니다.(단, 아래 내용은 법률 자문이 아니며 서비스 런칭 전 변호사 검토를 대체하지 않습니다.)

① 도장 생성·제공 자체의 합법성 — ✅ 문제 없음

형법상 처벌 대상은 "도장을 만드는 행위"가 아니라 **“행사할 목적으로 타인의 인장·서명을 위조 또는 부정사용하는 행위”**입니다. 형법 제239조(사인등의 위조, 부정사용)는 행사할 목적으로 타인의인장·서명을 위조·부정사용한 경우 3년 이하의 징역에 처한다고 규정하고 국가법령정보센터, 사문서위조죄(제231조) 역시 "타인의 문서"를 위조하는 경우에 성립합니다 법률신문 설명. 즉, 본인 이름으로 본인이 사용할 도장 이미지를 만드는 것은 처음부터 위반 행위가 아닙니다.실제로 도뉴·모두싸인·스탬프잇 등 유사 서비스가 정식 사업자로 운영 중입니다 도뉴 모두싸인 스탬프잇.

② 법적 효력 관련 — ⚠️ 오인 유발 방지 문구 필요

전자문서 및 전자거래 기본법상 전자서명은 "서명·서명날인·기명날인으로서의 효력"을 가질 수 있으나 전자문서및전자거래기본법, 단순 이미지 PNG는 서명의 "증거력"이 아니라 날인 자리 표시일 뿐입니다. 도장 이미지를 만들었다고 계약상 효력이 생기는 게 아니고, 진위·무결성은 별도 전자서명 기술의 영역입니다. 벤치마킹 대상인 스탬프NG조차 영상 안내에서 "중요한 계약서·공식 문서는 전자서명·직인 사용 규정이 따로 있다"고 명시합니다 참고 영상.→ 필수 조치: 서비스에 “본 이미지는 법적 효력을 보장하지 않으며, 중요 문서는 전자서명 서비스 및 소속 기관 규정을 확인하십시오” 면책 고지를 명확히 노출. (도뉴도 ‘법적 효력/보안’ 별도 페이지로 구분합니다 도뉴)

③ 인감도장·공공기관 직인 — 🚫 선제 차단 필요

인감(印鑑): 인감증명은 주민센터에 등록된 실물 인장으로만 가능하며, 온라인으로 만든 이미지와는 무관합니다. 그럼에도 사용자가 "인감"이라는 단어로 검색해 들어오는 경우가 많으므로, “인감도장 제작” 문구로 홍보하지 말고 “인감 용도로 사용 불가”안내를 넣을 것.

공공기관 관인/직인: 관인은 「행정업무의 효율적 운영에 관한 규정」으로 관리되는 행정기관 인장입니다 관인 설명 나무위키-관인, 공공기관은 자체 직인관리규정으로 인영·관리를 규정합니다 직인관리규정 예시.→ 필수 조치: “정부기관”, “관인”, “시청”, “구청” 등 특정 기관을 사칭하는 형태의 입력값 차단 로직 (키워드 필터 + 유사 도안 템플릿 미제공).

④ 개인정보보호법 — ✅ 클라이언트 사이드 처리로 사실상 회피 가능

비회원 도장 생성 서비스는 싸인오케이처럼 마케팅용 개인정보 수집 동의를 받는 구조가 있지만 싸인오케이, 스탬프NG는 **“이름은 이미지 생성을 위해 일시 전송, 로그·통계에 남기지 않는다”**는 무저장 정책으로 운영합니다 스탬프NG FAQ.→ 가장 강력한 리스크 완화책: 아예 서버로 이름을 전송하지 않는 100% 브라우저 렌더링(Canvas) 구조로 만들면 개인정보 수집행위 자체가 없어 개인정보처리방침 부담이 최소화됩니다. (부수 효과로 사용자 신뢰 마케팅도 가능 — “입력한 이름이 어디에도 저장되지 않습니다”)

⑤ 폰트 라이선스 — 🚨 가장 많이 놓치는 함정

도장 = 폰트를 이미지로 구워서 배포하는 구조이므로 폰트 라이선스 확인이 핵심입니다.

나눔글꼴(네이버): 개인·기업 포함 모든 사용자 무료, 폰트 파일 유료 판매만 금지, 상업적 사용 가능 네이버 공식 나눔스퀘어 네오→ 웹폰트 임베딩 + 이미지 생성 모두 안전

Google Fonts(OFL): 상업적 사용 무제한, 폰트 자체 판매만 불가 Google Fonts 설명→ 가장 안전한 선택지

눈누 등록 폰트: 전부 "상업용 무료"지만 용도별 제한(임베딩·BI/CI 제한 등)이 폰트마다 다르고, 폰트 파일 재배포·판매는 대부분 금지눈누 주의사항 설명 설명2→ 필수 조치: 초기 5~10개 서체는 OFL 또는 나눔 계열만엄선하고, 눈누 폰트를 넣을 경우 폰트별 라이선스 페이지를 확인해 "임베딩 허용 + 생성물 배포 허용"인 것만 사용. 각 폰트의 출처·라이선스를 사이트 내 크레딧 표기.

⑥ UI/디자인 벤치마킹 한계 — ⚠️ "기능"은 모방 가능, "표현"은 불가

타인의 UI도 창작성이 인정되는 경우 모방 시 저작권법 침해가 될 수 있습니다 지식재산권 설명, 화면 구성·배열이 유사하면 분쟁 소지가 있습니다 설명.→ 기능·흐름(4단계 UX, 투명 PNG 제공)은 자유롭게 벤치마킹하되, 로고·문구·화면 레이아웃·색감 조합을 그대로 복제하지 말 것.특히 스탬프NG의 카피 문구·예시 이미지 사용은 금지입니다.

데이터 흐름 (개인정보 리스크 제거가 핵심)

이름 입력→ 브라우저 내 JS에서 즉시 검증 (빈 값, 특수문자, 차단 키워드: “관인”, “정부”, “시청”, “구청” 등)

렌더링→ Canvas 2D API로 원형 테두리 + 세로/가로 글자 배치 + 서체 적용, 모두 requestAnimationFrame으로 실시간 미리보기

내보내기canvas.toBlob()으로 투명 PNG 생성 → URL.createObjectURL다운로드 (512px 기본, 1024px 옵션)

전송 경로 0→ 이름·생성 이미지는 네트워크로 나가지 않음. 서버는 정적 파일만 서빙 (Vercel/Netlify 무료 티어 가능)
